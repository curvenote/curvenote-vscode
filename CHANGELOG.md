# curvenote-vscode

## 0.2.0

### Minor Changes

- [#189](https://github.com/curvenote/core/pull/189) [`f915fed`](https://github.com/curvenote/core/commit/f915fed5a4532943231d9eb1f1df6dbd2c8b6f39) Thanks [@rowanc1](https://github.com/rowanc1)! - `.md` files open as MyST by default, as `.myst` files do. To keep them as plain Markdown, set `"files.associations": { "*.md": "markdown" }`; the README says how.

### Patch Changes

- [#188](https://github.com/curvenote/core/pull/188) [`910ce52`](https://github.com/curvenote/core/commit/910ce520bb027f82b5e9c610f1f773971c07175e) Thanks [@rowanc1](https://github.com/rowanc1)! - The extension downloads smaller: its code and the bundled language server are minified, about 40% smaller.
